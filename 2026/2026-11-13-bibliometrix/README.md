**23º Meetup R-Ladies Niterói**

## Resumo 
Aprenda a coletar dados na plataforma CAFe e explore o potencial do Bibliometrix, uma poderosa ferramenta em R para realizar análises bibliométricas e transformar dados em informações relevantes para a pesquisa científica.

Como utilizar os materiais: Faça o download ou clone este repositório para acessar os arquivos e reproduzir os exemplos apresentados durante o curso.

Antes da aula

  1. Descompacte toda a pasta RLadies_Niteroi no computador. Não execute os scripts diretamente dentro do arquivo ZIP.
  2. Abra o arquivo Rladies_Niteroi.Rproj no RStudio. Ele fica na pasta principal do material.
  3. No painel Files, confira as pastas scripts, dados, resultados, figuras e material_complementar.
  4. Abra scripts/01_minicurso_niteroi_alunas.R. Esse é o roteiro que vamos utilizar durante a aula.
  5. Acompanhe as orientações e execute os blocos na sequência. Vamos construir os mapas aos poucos!

Nosso ponto de partida é o projeto. Abra o arquivo .Rproj antes do script para que o R encontre os dados usando os caminhos definidos no material.

Visualizar um mapa no painel Plots não salva automaticamente um arquivo. As pastas de saída recebem os resultados quando os comandos de exportação são executados.

Pacotes utilizados

Antes do minicurso, instale os pacotes do roteiro principal que ainda não estiverem disponíveis no seu computador:

sf · tidyverse · ggspatial · terra · patchwork

Os pacotes geobr e geodata são possibilidades de aquisição de dados. Eles não são necessários para ler os arquivos locais do roteiro principal. O bônus também utiliza cowplot.

Quando precisamos de internet? Para instalar os pacotes e baixar os materiais. Com tudo preparado, a aula principal utiliza os dados locais. O script bônus inclui download de dados e pode precisar de conexão.

Para tudo funcionar

Mantenha a organização interna da pasta. Os scripts utilizam caminhos relativos, como dados/brutos/.... Mover ou renomear arquivos pode fazer com que o R deixe de encontrá-los.

Se aparecer uma mensagem de arquivo não encontrado, confira primeiro se o ZIP foi totalmente descompactado e se o projeto Rladies_Niteroi.Rproj está aberto. Depois, verifique o nome e a localização do arquivo indicado.

Se surgir um erro durante a execução, pare nesse ponto e peça ajuda antes de seguir para o próximo bloco. Assim conseguimos entender o que aconteceu juntas.
